# Kiosk scripts / Kiosk-Skripte

Turn a computer into a dedicated Computerfuchs learning computer.
Einen Rechner zum festen Computerfuchs-Lerncomputer machen.

| Script | System |
|---|---|
| [`linux/computerfuchs-kiosk.sh`](linux/computerfuchs-kiosk.sh) | Debian 12/13 and Raspberry Pi OS, with [Cage](https://github.com/cage-kiosk/cage) and Chromium |
| [`windows/Install-Kiosk.ps1`](windows/Install-Kiosk.ps1) | Windows 10 and 11 (Home, Pro, Education) with Chrome, Edge or Firefox |

Guide / Anleitung: [Deutsch](../docs/KIOSK.de.md) · [English](../docs/KIOSK.md)

> ⚠️ Not yet tested on real hardware. Noch nicht auf echter Hardware getestet.
